# Security policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Contact CollabCircle through the official website linked by the application and include the affected component, reproduction steps, impact, and a safe proof of concept.

Do not access data that is not yours, degrade service, or test third-party targets through the public scanner. We will coordinate remediation and disclosure for valid reports.

## Scope

This process covers ShieldCircle itself. Findings about scanned websites must be reported to their respective owners. Security fixes target the latest `main` branch.
