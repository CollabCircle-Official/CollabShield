# Contributing

1. Create a focused branch and never commit `.env` files or scan data.
2. Run `npm install` and `npm run check` before opening a pull request.
3. Run `npm run test:e2e` for interface changes.
4. Add tests for scoring, parsing, and network-boundary changes.
5. Document methodology changes in the README and changelog because they can change grades.

Report vulnerabilities through `SECURITY.md`, not a public issue.
